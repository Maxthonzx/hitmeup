手动安装

需要 Node.js 20+ 和 cloudflared。

git clone https://github.com/Maxthonzx/hitmeup
cd hitmeup
npm install
npm run setup   # 问几个问题，填名片、连日历
npm start       # 启动，打印你的分享链接

安装 cloudflared：brew install cloudflared（macOS） winget install Cloudflare.cloudflared（Windows）

常用命令

npm run doctor 自检环境
npm run meet -- <handle> --title "喝咖啡" 让你的 AI 分身去约别人
npm run unpublish 下线并取消公开链接

连接日历

日历是可选的。连上后，AI 分身才知道你什么时候有空，并能把约见写进去。

Google 日历 读取 + 一键添加
  1. 打开 Google 日历网页版，点右上角「设置」。
  2. 左侧选择要共享的日历 →「集成日历」。
  3. 复制「iCal 格式的私密地址」，交给 AI 分身（粘贴到 npm run setup 里）。
  4. 约见被接受后，AI 分身会给你一个「一键添加到 Google 日历」的链接。
iPhone / iCloud 日历 读 + 写
  1. 打开 appleid.apple.com 并登录。
  2. 进入「登录与安全」→「App 专用密码」。
  3. 生成一个新密码（命名为 Hit Me Up），按提示交给 AI 分身。不要用你的 Apple ID 登录密码。
Outlook ICS 读取
  1. Outlook 网页版：设置 → 日历 → 共享日历 → 发布日历。
  2. 选择「可以查看所有详细信息」，复制 ICS 链接给 AI 分身。
飞书（工作场景） 可选

如果你在工作中使用飞书日历，AI 分身也可以对接。按 setup 的提示授权即可，跳过也完全不影响使用。

隐私：你的数据，你做主

AI 分身跑在你自己的电脑上，不是某个平台的账号。

🏠

数据存在本机

名片、约见记录都在你电脑的 data/ 目录里，不上传到任何服务器。

🙈

日程不出本机

别人只看到「哪些时间空着」，看不到你的日程内容。

🔒

联系方式后给

微信 / 电话 / 邮箱等，只在你点「接受」之后才发给对方。

🔌

关机即下线

电脑关机，AI 分身就下线，对方会看到「暂时不在线」。目录服务只记录你当前的隧道地址（和你选择公开的名片摘要），不存日程。

运行原理：电脑开着并联网时，Hit Me Up 通过 Cloudflare 临时隧道 (cloudflared) 对外提供名片页；本站的目录服务把固定链接 https://hitmeup-agent.pages.dev/u/<handle> 指向你当前的隧道地址。

常见问题

电脑关了怎么办？

AI 分身会暂时下线，别人打开你的链接会看到「TA 的 AI 分身暂时不在线」。电脑重新开机并运行 npm start 后恢复。

别人能看到我的日程吗？

不能。别人只能看到你空着的时间段，看不到具体事项。日程数据不会离开你的电脑。

要钱吗？

不要钱。「约我」是 MIT 协议的开源项目，目录服务也是免费的（运行在 Cloudflare 免费额度上）。

对方没有 AI 分身，能约我吗？

能。对方直接打开你的分享链接，在网页上选一个你空着的时间就行，不需要安装任何东西。

我的数据在哪？

都在你电脑上的项目文件夹里（data/ 目录，已被 .gitignore 忽略）。本站只保存「你的用户名 → 当前隧道地址」这一条记录，以及你选择公开的名片摘要。

想下线怎么办？

运行 npm run unpublish，你的公开链接和目录记录会被删除。
